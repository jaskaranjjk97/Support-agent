# Getting Started with TaskFlow

## Creating your first workspace
1. Log in and click "New Workspace" from the top-right menu.
2. Give it a name and choose a plan.
3. Invite team members by email from Settings > Members.

## Creating a project
Inside a workspace, click "New Project". Projects contain tasks, sprints, and boards.
Each project can have its own members and permissions.

## Default roles
- Owner: full control, billing, deletion
- Admin: manage members and projects
- Member: create and edit tasks
- Viewer: read-only access
